Food Wastage Management System

A Streamlit-based web application designed to reduce food wastage by enabling efficient food donation, management, and redistribution. The system connects food providers (restaurants, events, households) with NGOs and organizations in need, ensuring surplus food is utilized instead of being wasted.

🚀 Project Overview

Food wastage is a major global issue. This project provides a technology-driven solution to manage surplus food efficiently. Using a simple and interactive Streamlit interface, users can register available food and help ensure timely redistribution.

🎯 Key Features

📝 Food donation entry (quantity, type, location, expiry time)

📍 Location-based food availability tracking

🏢 NGO/receiver access to available food details

⏱️ Time-sensitive food management to prevent spoilage

📊 Simple and interactive UI built using Streamlit

🌐 Web-based application (deployable on Streamlit Cloud)

⚙️ Installation & Setup
1️⃣ Clone the Repository
git clone https://github.com/your-username/Food-Wastage-Management-System.git
cd Food-Wastage-Management-System

2️⃣ Create a Virtual Environment
python -m venv venv

Activate the Environment

Windows

venv\Scripts\activate


Linux / macOS

source venv/bin/activate

3️⃣ Install Dependencies
pip install -r requirements.txt

4️⃣ Run the Streamlit App
streamlit run app.py


The app will open automatically in your browser 🚀
